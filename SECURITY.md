# Безопасность

Atlant wire7 — экспериментальная собственная композиция стандартных
криптографических примитивов. Работоспособность и тесты не доказывают
криптографическую надёжность или неразличимость трафика.

Не отправляйте в публичные issues действующие PBK, ключ сервера, секрет API,
ссылку подписки, необработанный конфиг или журнал с личными данными.
Для приватного сообщения об уязвимости используйте GitHub Private Vulnerability
Reporting, если он включён владельцем репозитория. При отсутствии канала
сначала запросите приватный способ связи, не публикуя детали эксплуатации.

Перед релизом обязательны проверки зависимостей, актуальные Go/UI/JVM-тесты,
сборка из чистых исходников и проверка отсутствия секретов в source/release.
Отдельно проверяются настоящие TUN, DNS/IPv6, kill switch, авария процесса и
смена сети на каждой целевой ОС. Один локальный RAM-бенчмарк их не заменяет.

Windows GUI пока запрашивает повышенные права. Keystore/DPAPI защищают
сохранённые профили в рамках модели ОС, но не от полного захвата ОС или
вредоносного процесса с достаточными правами пользователя.

Известные ограничения: [THREAT_MODEL.md](THREAT_MODEL.md).
